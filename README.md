# simonesalerno.it

Personal portfolio website built with SvelteKit 5 and TypeScript.

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm preview
```

## Tech Stack

- **SvelteKit 5** with TypeScript
- **Tailwind CSS v4** for styling
- **Cloudflare Pages** for deployment
- **JSON-based** content management with i18n
